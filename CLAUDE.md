# Project notes

## Changelog

Any commit that adds a new user-facing feature, or noticeably changes
existing behavior, must also add an entry to `src/changelog.ts`
(newest entry at the top) as part of that same commit. Write it in
plain language for someone using the app to plan a tent pitch — not a
copy of the commit message. Pure bug fixes and internal
refactors/cleanups don't need an entry.
